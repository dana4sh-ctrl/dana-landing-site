## איך לראות את הדף מקומית

פשוט פותחים את `index.html` בדפדפן (דאבל-קליק).
או, להרצה עם שרת מקומי (מומלץ, כדי שהתמונות ייטענו בוודאות):

```bash
# מתוך התיקייה dana-landing-site
python3 -m http.server 8000
# ואז פותחים בדפדפן: http://localhost:8000
```
